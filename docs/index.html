Phones

Or skip the app and use the phone's browser. On the computer, open Devices, Phones and switch on Phone link; then open the address it shows in the phone's browser, type the pairing code and add the page to the home screen. The phone and the computer must be on the same Wi-Fi. The phone's browser first warns that the connection is not private, because the computer makes its own certificate: check the address is the one Devices shows, then go on to it. Not yet tried on a real phone.

Installing

Installing Forge needs no administrator rights; if an app you choose needs a system permission (today only Power, to change power modes on Linux), Forge asks once at the end of its first-run setup, and Settings, Permissions changes it later.

Windows: run the setup. Windows may warn that the program is not signed yet: choose More info, then Run anyway.

Linux small installer: sh forge-get-0.3.2-linux-x64.sh (add --apps a,b for only some apps).

Mac: double-click the download to unpack it and drag Forge.app into Applications. It is not signed by Apple yet, so the first time open Terminal and run xattr -dr com.apple.quarantine /Applications/Forge.app (or choose Open Anyway in System Settings, Privacy & Security). The Mac downloads are built and checked on Linux only and have not been tried on a real Mac yet.

Updates

Forge looks for updates only when you press Check for updates in Settings, Updates; it never looks at the update list by itself. From there (or right-click an app) it updates one app or all of Forge, downloads only what changed and puts the old files back if anything fails. Your settings and saves are kept apart from the program and are never touched by an update.

If an app turns out to be unsafe or broken, the signed update list can mark it withdrawn. The next time you check for updates, Forge stops that app, takes out its program files and tells you why. Your own files and saves in it are never touched, and a Forge that never checks for updates is never changed.
